# Indestructible Blocks
**....is a Minecraft server utility mod that allows you to make any block you want, indestructible!**

***This mod may be used in any modpack.***

<img src="https://i.imgur.com/1hRqA1R.gif">

## ➕ Features
- The configuration file lets you edit what type of blocks should be indestructible.
- There is a usable tool to set indestructible block types by right clicking the blocks you want indestructible.
  - A secondary mode can be used for the tool (shift right click to change) which allows you to set a singular block to be indestructible instead of its type.
- The /ib command lets you set both the state of a block id and individual blocks.
  - block_id: This sub command will suggest ids of blocks to make indestructible or destructible.
  - set_state: This sub command overrides a block's indestructibility state. This works similarly to the fill command from Minecraft and involves taking two corners. When run, the command will set all blocks within the corners to either destructible or indestructible.

## ❓ FAQ
- Can I craft the tool used?
  - No, this is meant to be a creative utility. This mod is not meant for survival use.
